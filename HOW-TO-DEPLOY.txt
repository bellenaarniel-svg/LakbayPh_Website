========================================================
  LakbayPH — HOW TO DEPLOY ON RENDER (READ THIS FIRST)
========================================================

⚠️ IMPORTANT: Deploy as a "Web Service" — NOT a "Static Site".

Your site has a Node server + database. A Static Site has no server, so
bookings, admin login, price editing, and the styling/background all break
(that's why the page looked plain and had no background image).

--------------------------------------------------------
STEP 1 — Put these files on GitHub
--------------------------------------------------------
- Unzip this file first.
- Upload the FILES INSIDE the folder (package.json, server.js, db.js,
  mailer.js, render.yaml, public/, etc.) to your GitHub repo.
- DO NOT upload the folder itself — package.json must sit at the repo ROOT.
- On GitHub, confirm you can see package.json on the repo's main page.

--------------------------------------------------------
STEP 2 — Create the service on Render
--------------------------------------------------------
1. Render Dashboard → New +  →  **Web Service**   (NOT "Static Site")
2. Connect your GitHub repo.
3. Settings (most auto-fill from render.yaml):
     Root Directory : (leave BLANK)
     Runtime        : Node
     Build Command  : npm install
     Start Command  : npm start
     Instance Type  : Free
4. Environment variables (optional but recommended):
     ADMIN_USER = your-admin-name
     ADMIN_PASS = a-strong-password
   Email alerts (optional):
     RESEND_API_KEY = re_xxxxxxxx
     MAIL_TO        = you@gmail.com
     MAIL_FROM      = LakbayPH <onboarding@resend.dev>
5. Click "Deploy Web Service".

--------------------------------------------------------
STEP 3 — Done
--------------------------------------------------------
Wait ~2-4 min for "Your service is live 🎉".
Open the .onrender.com URL — full styling, background image, booking,
and admin dashboard will all work.

If you already made a Static Site by mistake: delete it in Render
(Settings → Delete), then redo Step 2 choosing "Web Service".

Note: Render's free plan sleeps after ~15 min idle; first visit then
takes 30-50 sec to wake up. Your database is on a persistent disk
(configured in render.yaml) so bookings are saved.
